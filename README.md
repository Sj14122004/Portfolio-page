#  Shivam Joshi - Developer Portfolio

A modern, responsive Full Stack Developer portfolio built with **HTML, CSS, and JavaScript**. It features a futuristic galaxy-themed UI, smooth animations, an interactive skills section, project showcase, and contact information.

## 🚀Live Demo

🌐 https://your-vercel-link.vercel.app


##  Features

- Responsive design for Desktop, Tablet & Mobile
- Modern glassmorphism UI
- Animated hero section
- Interactive Tech Stack section
- Project showcase
- About Me section
- Contact section
- Smooth scrolling and animations

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Vercel (Deployment)

##  Getting Started

Clone the repository:

```bash
git clone https://github.com/Sj14122004/Portfolio-page.git
```

Open the project:

```bash
cd Portfolio-page
```

Run locally:

Open `index.html` in your browser.
